# Vibe

Flutter tabanlı Android sesli sohbet ve sosyal uygulama başlangıç projesi.

## APK oluşturma
GitHub Actions sekmesinden **Build Vibe Android APK** iş akışını çalıştırın. Başarılı çalışmanın sonunda **Vibe-Android-APK** artifact dosyasını indirin.

> Bu sürüm arayüz prototipidir. Gerçek hesap, sunucu, canlı ses, mesajlaşma, ödeme ve coin işlemleri henüz bağlı değildir.
